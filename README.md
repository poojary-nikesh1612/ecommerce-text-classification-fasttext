# E-Commerce Text Classification using FastText

This project demonstrates product category classification using FastText supervised learning on an e-commerce dataset.

The workflow includes:
- Text preprocessing using Regex
- Label formatting for FastText
- Train-test splitting with stratification
- Training FastText supervised classification model
- Predicting product categories from product descriptions

## Technologies Used

- Python
- Pandas
- FastText
- Scikit-learn
- Regex

## Dataset
Dataset: Ecommerce Text Classification Dataset
